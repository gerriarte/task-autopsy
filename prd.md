# PRD - Task Autopsy

## Executive Summary

**Task Autopsy** es un sistema de decomposición inteligente de tareas complejas que transforma el entusiasmo en disciplina para profesionales con TDH/TDAH.

**Problem:** Ger abandona tareas operativas/venta a mitad de camino, análisis parálisis en priorización, pero se concentra mucho en lo técnico.

**Solution:** Sistema que:
1. Desglosa tareas complejas en micro-tareas (15-30 min)
2. Detecta gaps de conocimiento → micro-learnings
3. Gamificación dopaminérgica (streaks, micro-victorias)
4. Priorización inteligente (no manual, guided)
5. Offline-first + sync automático

**Success Metrics:**
- Completar 80%+ de tareas operativas (vs actual ~40%)
- Mantener streak de 5+ días = disciplina = hábito
- 0 abandonos a mitad de camino
